## 这是什么

本仓存放 **制作与数字音乐**（Production & Digital Audio）的全部条目源码 —— **纯 Markdown**，一个条目一个文件。

| 目录即文件 | 说明 |
|---|---|
| `<slug>.md` | 一个条目（如 `interval.md` → <https://prod.midicn.com/interval/>） |

条目内含 front-matter（标题 / 摘要 / 分类 / 双语字段）与正文。
正文用 `::: zh` 与 `::: en` 两个区块承载**中英双语**，两者**同步维护**。
